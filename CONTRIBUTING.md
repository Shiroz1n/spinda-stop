# Como contribuir

1. Abra uma issue curta ou descreva o problema no pull request.
2. Crie uma branch (`feat/...`, `fix/...` ou `docs/...`).
3. Mantenha a alteração no escopo e atualize a documentação afetada.
4. Rode `npm run lint`, `npm test` e `npm run build` quando esses comandos existirem.
5. Abra um pull request com o que mudou, como foi verificado e quais limites continuam abertos.

Commits seguem Conventional Commits em inglês, por exemplo `feat(dex): add form filters`. Não inclua tokens, respostas brutas de serviços, códigos de partida, sprites ou arquivos gerados pelo importador.
