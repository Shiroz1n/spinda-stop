# Spinda Stop

Uma oficina independente para explorar Pokémon, montar times e, mais adiante, organizar torneios comunitários de Pokémon Champions. Doubles é o primeiro formato. O projeto não tem vínculo com The Pokémon Company, Nintendo, Creatures ou GAME FREAK.

## Estado do projeto

O repositório está na fundação da fase 0: fontes, limites de uso, regras de contribuição e direção visual estão documentados. O catálogo e o construtor local entram na fase seguinte, em um pull request separado.

Dados gerais da PokéAPI não indicam se um Pokémon está disponível ou é permitido no Champions. Essa confirmação depende do formato e do regulamento vigentes. Até essa fonte ser validada, o projeto mostra disponibilidade e legalidade como desconhecidas.

## O que vem no produto

- Pokédex com espécies e formas identificadas separadamente.
- Construtor de seis integrantes, análise e calculadora de dano.
- Dados competitivos com fonte, período e tamanho da amostra.
- Eventos comunitários com inscrição, pareamento e confirmação de resultados.

As partidas continuam acontecendo dentro do jogo. O site organiza equipes e eventos; não cria partidas ou serviços oficiais do Pokémon Champions.
