# Direção visual do Spinda Stop

O [design system](SPINDA_STOP_DESIGN_SYSTEM.md) é a fonte atual para direção, tokens, componentes, estados e telas. Use também o [UI Humanizer](UI_HUMANIZER.md) para revisar padrões visuais genéricos. `AGENTS.md` define quando consultá-los.

A identidade combina menus de RPG portátil inspirados em FireRed/GBA com uma ferramenta competitiva de leitura rápida. Sprites e formas exatos, fonte e período das métricas e o fluxo do usuário têm prioridade sobre decoração. A origem e os direitos de sprites e marcas ficam em [créditos](THIRD_PARTY_LICENSES.md). A inspiração não implica copiar código, CSS ou assets exclusivos dos sites de referência.

**Importante:** versões anteriores deste arquivo descreviam uma paleta azul-petróleo e menta que deixou de corresponder a `apps/web/src/styles.css` após a direção FireRed/GBA do PR #28. O inventário de tokens vigente e o trabalho visual pendente estão no design system. Confira o código e as capturas antes de afirmar que um padrão foi implementado.
